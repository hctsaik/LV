# 需求:標註讀回要「留得住」

我(電腦視覺工程師)在 LV 選樣送到 Labeling、標註者標完、我回 LV 按「📥 套用讀回結果」
把新標籤套回來——但我發現:**只要重新 Run 一次資料夾,剛套用的修正就全部不見了。**

因為 Run 會從資料夾重建 records、標籤重新從磁碟讀,而讀回只改了記憶體裡的 records。
等於我每次重開都要重標一次,主動學習迴圈根本轉不起來。

我要的:

1. **讀回的修正要跨重開存活**——重 Run 後,被標註者改過的圖,LV 裡顯示的還是改過的標籤。
2. **絕不能動到我的原始資料夾**——我的資料集是唯讀的真相,修正不可以偷寫進去
   (公司規定 + 我要能隨時回到原始狀態)。
3. **每一筆修正要留痕、可稽核**——誰、什麼時候、把哪張圖從什麼改成什麼、為什麼。
   出事要查得到、要能回溯。
4. **要能收成一個「這一版的資料」**——把原始 + 修正收成一份明確的版本(含修正清單),
   交給訓練或下一輪,而不是一堆散在記憶體裡的暫時狀態。

我不在乎修正存在哪(那是技術細節),我在乎的是「改過就算數、原始不被動、查得到、收得成一版」。
