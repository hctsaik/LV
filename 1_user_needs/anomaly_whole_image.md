# 需求:沒有 YOLO 標籤時,直接拿「整張影像」做瑕疵偵測

## 使用者是誰 / 情境(Persona & Context)

我手上常常只是**一資料夾的圖片**——例如每張就是一顆水果、一個產品、一片成品的特寫照——
**沒有畫框、也沒有標註檔**。我只想知道:這堆圖裡哪幾張「看起來不對勁 / 壞掉了」。

現在的瑕疵偵測工具一定要我準備 YOLO 物件偵測資料集(要有 `images/` 還要有 `labels/` 框)。
我根本沒有那些框,也不想為了用這個功能先去標一輪框。

## 想達成的目標(Jobs to be done)

- 我想要**直接丟一個只有圖片、沒有標籤的資料夾**進去,讓它把**整張圖當成要檢查的對象**,
  這樣我就能在完全沒標註的情況下找出異常的圖。
- 我想要它跟現在一樣給我:每張圖一個**異常分數**、可以**排序**、在散點圖上看分布、點開**看大圖**、
  把可疑的**挑進購物車匯出**。
- 我希望「整張影像」和「YOLO 物件」這兩種用法能**並存**:有框的資料夾照舊逐物件做,沒框的就整張做。

## 痛點(Pain points)

- 沒有 `labels/` 時,工具直接跳「**找不到 YOLO 物件**」然後什麼都不給我——等於這個功能對我**完全不能用**。
- 為了用它,我得先去把每張圖標一個框,但我的圖根本就是「一張圖一個東西」,標框是多餘的工。
- 我會卡在這一步,乾脆放棄,改用別的工具或人工一張張看。

## 使用者眼中的「成功」(可觀察)

- 我選一個**沒有 labels 的圖片資料夾**,按建模 / 套用,**不再跳「找不到 YOLO 物件」**。
- 它跑得出來:**每一張圖都有一個異常分數**(不是每個框),散點圖上每個點 = 一張圖,排序 / 看圖 / 匯出都正常。
- 我**很快就知道**現在是「整張影像」模式在跑(畫面有明講),不會搞不清楚它到底在算什麼。
- 如果我選的資料夾**剛好有 labels**,它仍然能照原本的「逐物件」方式做——我沒有失去舊用法。

## 不在乎 / 可放棄的(Non-goals)

- **不在乎**整張影像模式能不能分辨「圖內有好幾個東西、分別評」——整張就是一個對象,這就夠了。
- **不在乎**這個模式有沒有「分類頭 / 自動分辨缺陷類型」——整張圖我也沒有缺陷類型的標籤,沒有頭很正常。
- **可接受**由我自己在畫面上選「整張影像」這個模式;若它能在偵測不到 labels 時自動建議切過去更好,但不是必須。
- **不在乎**整張圖裡的小背景——我的圖本來就是把主體拍滿、背景單純,整張算我能接受。
