# 需求:晶圓空間簽名分析(把瑕疵攤回晶圓地圖看模式)

> 2026-07-19,由使用者口述整理(feature 粒度)。

## 1. 使用者是誰 / 情境 (Persona & Context)

我是半導體產線的檢測資料負責人。我的檢測影像**每張對應一顆 die(或一個檢測點)**,
手上另有一張 CSV,欄位有 wafer/lot 批號和 die 的座標(還有機台、日期等)。
瑕疵偵測工具已經能告訴我「哪些 die 可疑」,但那是**一顆一顆看**;
我真正要跟製程工程師對話時,講的是**一片一片晶圓**:

- 「這片的缺陷全擠在**邊緣一圈**」→ 邊緣製程(塗佈/蝕刻邊緣效應)出問題。
- 「缺陷連成**一條線**」→ 機械刮傷(手臂/夾具)。
- 「缺陷**擠成一團**在某區」→ 局部污染或曝光問題。
- 「**同一批(lot)的好幾片都同一種模式**」→ 該批共用的設備/程序出問題。
- 「就是**隨機散的**」→ 大概率不是系統性問題,別浪費工程師時間。

空間模式是根因追查的**最強線索**;現在這條線索完全斷在「逐張影像」這層。

## 2. 想達成的目標 (Jobs to be done)

- 我想要**把瑕疵偵測的結果攤回晶圓地圖**:一片晶圓一張圖,每顆 die 在它真實的
  座標位置上,可疑的亮起來,這樣我一眼就能看出模式。
- 我想要工具**直接告訴我這片是哪種模式**:聚一團/偏邊緣/一條線/看不出模式,
  講人話,這樣我不用自己瞇著眼判斷。
- 我想要**同一批多片並排看**:一個 lot 的晶圓地圖排在一起,哪幾片同模式一目了然,
  這樣我就能說「這批有系統性問題」。
- 我想要**點地圖上的 die 能看到那張原始影像**,這樣我確認模式時不用切畫面去翻圖。
- 我想要能**把晶圓地圖和結論匯出**(圖+表),直接貼進根因報告。

## 3. 痛點 (Pain points)

- 現在要看空間模式,得把可疑清單匯出 Excel、自己按座標畫散點圖——半小時起跳,
  而且每片晶圓要畫一張,實務上根本沒人做,線索就這樣丟掉。
- 跟工程師開會時只能口頭說「感覺偏邊緣」,拿不出圖、也說不出「多有把握」,
  常被一句「你確定不是剛好?」擋回來。
- **最討厭工具把隨機散佈硬說成有模式**——狼來了幾次之後,工程師就不信這個工具了。
  寧可它常說「看不出模式」,說「有模式」時就要真的有。

## 4. 使用者眼中的「成功」(可被觀察)

- 我選好結果和那張 CSV、按一個鈕,**每片晶圓一張地圖**出現,可疑 die 亮起,
  die 的位置和我認知的晶圓佈局一致(邊緣是邊緣、中心是中心)。
- 每片地圖旁邊**一句結論**:「偏邊緣(可信)」「聚一團(可信)」「線狀(可信)」
  或「看不出模式」;隨機撒的資料它**從不**說有模式。
- 同 lot 的地圖**排在一起**,同模式的片子我掃一眼就能點出來。
- 點某顆亮起的 die,**看得到那張原始影像**(或它的縮圖)。
- 匯出後拿到的圖和表,不用再加工就能貼報告。
- CSV 欄位對不上時(座標缺、wafer 欄不知道是哪個),它**明講**哪裡對不上、
  讓我指定欄位,而不是默默少畫幾顆 die。

## 5. 不在乎 / 可放棄的 (Non-goals)

- 我不需要它**自動指出根因**(「這是塗佈問題」)——模式講清楚就好,根因我們自己判斷。
- 我不需要涵蓋所有教科書模式(donut、半月、複合模式…)——先把
  **聚一團/偏邊緣/線狀/隨機**這四種基本款做誠實就很有用了。
- 我不需要跨 lot 的自動趨勢追蹤(這週比上週多幾片邊緣型)——先看單批就好。
- 我不在乎地圖美不美(不用擬真晶圓外框),位置對、亮暗清楚就行。
- 檢測點不是完整格點也沒關係(抽檢),有幾顆畫幾顆,不用幫我補內插。
