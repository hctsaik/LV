# 需求:我教過它的瑕疵類別,新資料進來時幫我「先填好」,我只做確認

## 使用者是誰 / 情境(Persona & Context)

我還是那個產線品管工程師。我已經花過時間教這套工具認得幾種瑕疵
(建模時給過瑕疵類別、每類都給了不少例子),③挑樣的佇列徽章也確實會顯示
它猜的類別——**它明明已經認得了**。

但每天新資料進來,我還是得**一顆一顆自己標**,包括那些它其實已經猜得又準又有把握的。
同一種刮痕標到第兩百次的時候,我真的覺得這工作不該是我做的。

## 想達成的目標(Jobs to be done)

- 我想要:對**我教過的類別**,新資料進來時它**先把類別填好**(附上它多有把握),
  這樣我就只需要**看一眼、按確認或改掉**,不用每顆從零開始標。
- 我想要**先看再收**:給我一張預覽清單——每顆的縮圖、它猜的類別、把握程度、
  收不收——我確認沒問題才收下,**最終決定權永遠在我**。
- 我想要**挑類別**:我可以說「這批只幫我預標刮痕和缺角」,其它類別它別自作主張。
- 我想要**它老實說不知道**:沒把握的、看起來是新東西的,就留給我,
  **寧可留白也不要亂猜**——錯的預標比沒有預標更花我時間。
- 我想要**把預標結果存成標註檔、放到我指定的資料夾**,讓我後續的訓練流程直接吃。
  **絕對不准動我原本的資料夾。**
- 在「持續監看」的佇列裡,我希望每顆旁邊**直接顯示它的建議**,我按一下就採納,
  不用切到別的畫面。

## 痛點(Pain points)

- 重複標同一類瑕疵幾百次,又累又容易手滑標錯;我的半小時標註預算全被
  「它其實會的東西」吃光,真正需要我判斷的難例反而沒時間看。
- 現在它的判斷只是畫面上的一個徽章,**看得到、帶不走**:我沒辦法把它變成
  我訓練流程能用的標註檔。

## 使用者眼中的「成功」

- 一批新資料進來,預覽清單裡**大部分它認得的都已填好類別**;我按一次
  「接受全部有把握的」,剩下要我親手處理的只有少數難例。
- 它填的類別我抽查起來**幾乎都是對的**;沒把握的它明確標成「不確定」而不是亂填。
- 匯出的標註檔放進我指定的資料夾,我的訓練工具**不用任何轉檔**直接能用。
- 我原本的資料夾**一個位元組都沒被改**。

## 不在乎 / 可放棄的(Non-goals)

- **不需要全自動**:我不要「它標完直接算數」;人工最終確認是底線,不是負擔。
- **v1 不需要幫沒畫框的圖生框**:先處理「框已經有、類別要填」的情況就好;
  完全沒標註的圖之後再說。
- 不急著跨機器、不急著排程自動跑;跟著現有的掃描/監看流程走就行。
