# 需求:從類別相似度分布挑出該檢查的圖／物件，並用人確認的誤標評估門檻

## 使用者是誰 / 情境

我在 Visualize 看過混淆熱圖和「疑似標錯」，那些分數能告訴我哪兩類容易混，但不能讓我看到**每一筆**離同類有多近、離最近的異類有多近。我需要從分布裡點進原圖和鄰居，再決定要不要放進既有選取／購物車去 Labeling。

我還沒有全包人工真值時，仍希望用一個明確的 margin 門檻預覽「先檢查哪些」和大概工作量。有一批我親自確認過「原標對／錯」的資料後，我才想看這個挑選規則的 Precision／Recall。那些數字衡量的是**找出誤標的能力**，不是分類模型準不準。

## 想達成的目標

- 對目前模型的原始高維特徵，看到每類的同類相似度、最接近異類相似度、以及兩者差距（margin）。
- 點散點或勾表格就能對到原圖／ROI，並看到用來計分的同類與異類鄰居。
- 用一個門檻預覽候選和工作量；只有我明確按按鈕才併入 LV 選取或購物車。
- 下載可重算的 CSV／JSON 證據。不自動改標、不另開一套審查系統、不把舊灰帶入口救回來。
- 有人工評估集時，才顯示覆核 Precision／Recall，並能下鑽 TP／FP／FN／TN 圖片。

## 痛點

- 現有「鄰居多數是別類」和 min-max 優先分數不是同一件事，不能拿來畫這個分布。
- 沒真值時不該出現假的準確率。
- 同張原圖的兩顆物件不能混成一筆。來源資料集不能被寫入。

## 使用者眼中的成功

- 計算後每類有 box 和可追溯的點；narrow 分布也能放大看。
- 拖動門檻時候選數跟著變，鬆開後集合等於最後那個精確值。
- 匯入我填過的評估 JSON 後，PR 與手算一致；沒填完就明白寫「尚不可用」。
- 改標、改圖、換模型後舊結果不能再被拿去選取或當已驗證證據。
