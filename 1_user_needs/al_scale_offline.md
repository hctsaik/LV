# 需求:資料很多也能用的主動學習,以及一個「自己盯著資料夾、幫我挑出該看的」離線服務

## 使用者是誰 / 情境(Persona & Context)

我是產線的品管工程師(也可能是資料集管理者)。我懂「哪些圖看起來不對勁」,但我不懂裡面的技術。
我的時間很貴——**一天最多只願意花大概半小時做標註**。

我現在用你們的瑕疵偵測 / 主動學習畫面,是**靠我自己一步步操作 GUI**:選資料夾、建模、套用、
然後在畫面上挑出可疑的來看、來標。小資料時很好用。但我遇到兩個越來越痛的狀況:

1. **我的資料越來越多**(幾萬張,甚至十萬張)。我怕畫面會跑不動、或要等超久。
2. **我的資料夾是「活的」**——每天都有新圖自動落進來(相機、產線)。我不想每天手動重跑一輪,
   我希望有個東西**自己在背後幫我盯著**,每天早上就把「今天最該我看的那些」準備好。

## 想達成的目標(Jobs to be done)

### A. 資料很多時也要能用
- 我想要**「掛著讓它慢慢跑」**:資料很多的時候,它可以一批一批處理,我中途去忙別的、
  甚至關掉電腦,**明天回來能接著上次的地方繼續,不要每次都從頭來**。
- 我想要**「還沒跑完就先看到目前最可疑的」**:不用等全部算完,跑到一半我就能先看目前排前面的,
  只要畫面**老實告訴我這是暫定的、還沒看完全部**就好。
- 我想要**「只給我我要的結果就好」**:資料量大的時候,我其實不需要看每一個點、每一張縮圖。
  我可以先講「我今天想看**大約一百個**最該處理的」,它就**只把那一百個排好給我**,不要硬塞一張
  塞滿幾萬個點、卡到動不了的大圖給我。

### B. 一個離線的「自動幫我挑」服務
- 我想要**指定一個資料夾**(先假設這個資料夾的內容會一直更新),然後有個**在背後跑的服務**,
  **不用開著那個互動畫面**,就能照「主動學習的目標」自動幫我找出
  **最該我花時間去標註、或去釐清的前一百個 case**。
- 我想要它**只看新的、還沒處理的**:資料夾昨天已經看過的、我已經標過的,今天不要再塞給我一次。
- 我想要**在畫面上就能設定這個服務**:目標是什麼、看哪個資料夾、一次挑幾個。設定好之後,
  我希望能**把這份設定「存成一個檔 / 匯出」**,讓背後那個服務照著這份設定去跑——
  我不想為了改個設定還要去動什麼程式或指令。
- **現在**服務跟我看的畫面在**同一台電腦**就好;但我知道**以後很可能**服務會在**別的機器**上跑
  (例如放產線旁邊那台),我在**自己的電腦**上看結果。所以請不要把它做成「一定得同一台」才行。
- 我更新了判斷標準之後(例如我重新確認了一批正常樣本、把模型變聰明了),我希望**舊的排序會依
  新標準重新算過**,不要繼續給我看一份**過時**的排名。

### C. 我最後要能真的把這些 case 看完、標完
- 不管是「掛著跑」還是「離線服務挑出來的」,最後我都要能在**一個清單 / 佇列**裡,
  **一個一個看縮圖、看它為什麼被挑出來、然後做決定**(這是正常的 / 這是瑕疵、是哪種 / 這個先跳過)。
- 我標完的每一個決定都要**算數**:下次挑的時候要**變聰明**,不要一直拿同一批來煩我。

## 痛點(Pain points)

- 資料一多,我最怕的就是**畫面轉圈圈、或直接卡死**,然後我什麼都做不了、也不知道它到底在幹嘛、
  還要多久。等太久我就乾脆不用了。
- 我**不可能一直開著那個畫面等它跑**。我要的是「我不在的時候它也有在幫我做事」,
  我回來就有結果可看。
- 現在每天新圖進來,我得**自己記得重跑、自己記得哪些看過了**。很煩、也很容易漏。
- 我最怕**它動到我的原始資料夾**。那是產線的原始資料,**只能讀、絕對不能被它改或寫東西進去**。

## 使用者眼中的「成功」(可觀察)

- **接著跑**:我把幾萬張的資料掛著跑,關掉再打開,按「繼續」,它**從上次的進度接著走**,
  不是從 0 開始。
- **邊跑邊看**:跑到大概三成的時候,我**已經能看到目前排最前面的那些**,而且畫面上**明講**
  「這是暫定的,只看了大約三成」。
- **只看該看的**:我設「一次一百個」,畫面**直接給我排好的一百個 + 一張分數分佈的小圖**,
  **不用等全部跑完、也不會卡**。
- **背後自己跑**:我設定好一個資料夾和目標、把設定匯出,那個離線服務**在我沒開畫面的時候
  自己跑過一輪**;隔天我打開畫面,佇列裡就是**新的、我還沒看過的**該看清單。
- **不重複煩我**:我昨天已經標過的、已經看過的,今天的清單裡**不會再出現**。
- **講得出理由**:每一個被挑出來的 case,畫面**用人話告訴我為什麼**——像是「這張很不像正常的」、
  「模型對這張拿不準」、「這張跟你之前標的矛盾」。
- **服務有沒有在跑我看得到**:我打開畫面時,如果那個服務**很久沒成功跑過**了,畫面會**明顯提醒我**
  上次成功是什麼時候,不會讓我以為有在跑、其實早就停了。
- **不碰我的資料**:整個過程跑完,我的**原始資料夾一個位元組都沒被改過**。
- **設定可帶走**:我在畫面上調好的設定,能**存成一份檔**;之後服務(不管在這台還是以後在別台)
  就照這份檔跑,我改設定只要在畫面上改、再匯出,不用碰別的東西。

## 不在乎 / 可放棄的(Non-goals)

- **不在乎即時**。服務**一天跑幾次**、甚至我手動按一下「現在跑一輪」就好,**不需要秒級更新**。
- **不在乎多人同時標**。現在就我一個人用。
- **不在乎推播通知**(email、手機提醒都不用)。我**打開畫面看得到狀態**就夠了。
- **不在乎**它把每一張都畫在一張大散點圖上給我看——資料多的時候我**本來就不想看全部**,
  給我「該看的那一百個」比給我「全部但卡死」有用太多。若小資料時想看全貌的散點圖,那是加分、不是必須。
- **可接受**設定服務、匯出設定這件事要我在畫面上做幾個步驟——只要**不用寫程式 / 不用背指令**就好。
