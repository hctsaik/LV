# 需求:一鍵資料體檢報告 + 把製程資訊掛上影像(可依機台/配方切開看)

## 使用者是誰 / 情境(Persona & Context)

我是做製程分析的工程師,同時也是要對主管交代「資料到底可不可靠」的人。
現在工具裡其實**什麼檢查都有**——重複、洩漏、標籤分歧、覆蓋缺格、離群——
但它們散在五六個畫面,每個都要我手動點進去看、自己截圖拼湊。

另外,我手上每張影像其實都有對應的**製程資訊**(哪台機、哪個配方、哪個批號、哪天拍的),
通常就存在一張 Excel/CSV 裡。現在工具完全不認識這些欄位,所以我永遠回答不了
「**是不是某一台機的資料特別髒?**」「**驗證集有沒有涵蓋到每台機?**」這種主管一定會問的問題。

## 想達成的目標(Jobs to be done)

- 我想要選一個資料夾、按一顆「產生體檢報告」,**一次**得到一份量化報告:
  重複幾張(佔比多少)、train/val 有沒有互相洩漏、有沒有「同一張圖被標成不同類」、
  每個類別各幾張、驗證集缺了哪些類、最可疑的離群圖是哪幾張——
  這樣我開會時**貼一份報告**就講完,不用截六張圖。
- 我想要**丟一個 CSV**(檔名對機台/配方/批號那種),讓報告能**依這些欄位切開看**:
  每台機各幾張、哪台機重複最多、驗證集少了哪台機的資料。
- 我想要報告能**存下來**(可以貼進簡報/傳給同事的格式),不是只能在畫面上看。
- 報告裡每個數字旁邊,我想看得到**它是怎麼算的**(用什麼方法、門檻多少),
  不然被主管問「這個 317 筆怎麼來的」我答不出來。
- CSV 對不上的影像(檔名打錯、缺列),我想**明確知道有幾張沒對上**,而不是默默略過。

## 痛點(Pain points)

- 同一份「資料品質」的故事,我現在要開五個畫面、截六張圖、自己在簡報裡拼——
  每次資料更新就得重來一遍,半小時起跳。
- 主管問「B 機台的資料品質如何」,我只能回「工具看不到機台」——分析停在影像端,
  到不了製程端,等於最關鍵的問題回答不了。
- 數字沒有出處:我口頭說「重複大概一成」,被追問細節就心虛。

## 使用者眼中的「成功」(可被觀察)

- 選資料夾 → 按一顆鈕 →(等得起,幾分鐘內、有進度)→ 出現一份報告:
  每一節有**一個數字 + 一句白話 + 一行「怎麼算的」**。
- 我故意放進去的問題它**都抓得到、數字對得上**:複製 3 張重複圖,報告就寫 3;
  train/val 放同一張圖,洩漏就是 1;同一張圖標兩個類,衝突就是 1。不多報、不少報。
- 丟了 CSV 之後,報告多出「依機台/配方」的分組段落;CSV 有 5 張對不上,
  報告明寫「5 張未匹配」。
- 按「匯出」,得到可以直接貼簡報/寄給同事的檔案。
- 沒給 CSV 也完全能用(分組段落消失而已,其他照常)。

## 不在乎 / 可放棄的(Non-goals)

- **不在乎**報告自動修問題(刪重複、改標籤)——我要的是「看清楚」,動手我自己來。
- **不在乎**接 MES / 資料庫即時撈製程資料——CSV 手動丟就好。
- **不在乎**嚴重度分級/簽核/豁免流程——我一個人用,不需要工作流。
- **不在乎**排程自動跑——要看的時候按一下就好。
- **可放棄**「兩個資料夾互比距離」——先把單一資料集(含 train/val)體檢做好。
- **可放棄**很漂亮的排版——清楚、數字對、可匯出,比美觀重要。
