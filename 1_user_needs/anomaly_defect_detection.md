# 需求:物件級瑕疵偵測(把整批資料分出好/壞)

> 本文件是「終端使用者」的願望陳述,**不含任何技術**。供 `/po` 收斂、砍範圍。
> (已依 2026-06-22 的討論更新:確定是「同物件的好/壞」、要看哪裡怪、要分布圖、要能選流程。)

## 1. 使用者是誰 / 情境 (Persona & Context)
- 我是做**視覺品檢 / 資料集檢視**的人。手上有一個資料夾,裡面是**大量同一種物件**的照片
  (例如某零件、產品、瓶罐…),物件位置我**已經有框好的標註**(每張圖都標好了物件在哪)。
- **絕大多數是正常 / 良品,只有極少數有瑕疵 / 異常**;而且我**沒有足夠的瑕疵樣本**可以拿來「教」模型,
  壞的很少、長相千奇百怪、無法事先窮舉。
- 「好的」其實**不只一種**(大概 3~5 種長相不同的良品),量都很大;「壞的」大概 1~2 種,量很少。
- 我用它的時機:**剛拿到一批新資料**,想在幾分鐘內把「壞的 / 怪的」從一大堆好的裡面分出來。
- 我希望它**長在我現在用的這個分析工具裡**(多一個頁籤),不要另外開程式。

## 2. 想達成的目標 (Jobs to be done)
- 我想要**載入一個資料夾**(裡面圖片都已經框好物件),它就**自動把每個框出來的物件抓出來**,我不必手動裁切。
- 我**不想自己一個個標好壞**。我希望它**先看一小撮**(抽樣幾十個物件就好),**自動把長得像的好的歸成一群**,
  把**少數怪的 / 離群的挑出來問我「這算壞嗎?」**;我**只要點頭/搖頭確認**,它就學會我的標準。
- 確認完後,我想要它**照這個標準,把整批資料集的每個物件都分成好 / 壞**,並給我一個「有多可疑」的分數。
- 我想要一張**分布圖(2D 或 3D)**,能看到**好的擠成一團、壞的散在外圍**;而且我能**直接在圖上圈選**可疑的點、
  **丟進清單**——這跟我現在看 embedding 分布的習慣一樣。
- 對每個可疑物件,我想要能**看到它哪裡怪**(在圖上把可疑部位標出來,像熱區),這樣我能一眼確認是真瑕疵還是誤判。
- 我想要能**自己決定流程**:要嘛「**先抽樣讓我確認、再整批跑**」,要嘛「**直接整批跑**」。
- 我想要把**確認是壞的物件挑出來、匯出**;匯出的是**原圖**(不是被裁過的小圖)。

## 3. 痛點 (Pain points)
- 現在只能**人工一張張翻**,幾千~幾萬個物件看到眼花還是會漏。
- 想用 AI 又卡在「**沒有足夠瑕疵樣本可訓練**」,而且瑕疵種類太多無法事先窮舉。
- 就算工具丟我一個冷冰冰的「異常分數」,**我也不敢信**——我要看到「它認為哪裡有問題」才敢採用。
- 我的資料**非常不平衡**(良品一大堆、瑕疵極少)。很多方法在這種情況下**整批都說正常或整批都說異常**,沒有鑑別力。
- 我**不想花大把時間標註**;最好系統先幫我把候選挑出來,我只負責確認少數幾個。

## 4. 使用者眼中的「成功」(可觀察)
- 載入資料夾後,**不用手動裁切**就看到物件被一個個列出來。
- 抽樣那一步,系統**自動分好群**,並只把**少數**離群/可疑的丟給我確認(不是要我看幾十個全部)。
- 我**只用點頭/搖頭確認少數幾個**,就能讓它跑完整批;**全程不寫程式、不碰命令列**。
- 跑完後,整批每個物件都有**好/壞標記 + 可疑分數**,而且**從最可疑排到最不可疑**;真正的壞件**大多落在最前段**。
- 分布圖上,**好的明顯聚成團、壞的明顯在外圍**;我能**框選外圍的點**,被選的就進清單。
- 點開一個可疑物件,**標出來的可疑部位對得上我肉眼看到的缺陷位置**。
- 第一次跑比較久我可以接受;但我**換掉 / 增減「正常」的認定或重跑**時,**不要每次都從頭等一樣久**。
- 我可以把確認的壞件**一鍵匯出原圖**。

## 5. 不在乎 / 可放棄 (Non-goals,給 PO 砍的空間)
- 我**不在乎**它用什麼演算法、模型、跑 CPU 還 GPU。
- 我**不要求它幫我下不可推翻的最終結論**;它分好/壞 + 給分數,**最後我還是會自己看、自己圈**。
- 我**不要求說出瑕疵種類名稱**(刮傷 / 凹陷 / 污漬…);先把「好 vs 壞」分出來就好,細分種類以後再說。
- 我可以接受**先只支援「同一種物件(可有數種良品長相)」的資料夾**;完全不相干的多類別大雜燴**先不用**。
- 我**不要求即時 / 串流**;批次跑完給我看就好。
- 我**不堅持只給少數正常範例**:我可以丟很多好的進來,也可以讓系統自己從抽樣裡找出「好的群」——哪個省事用哪個。
