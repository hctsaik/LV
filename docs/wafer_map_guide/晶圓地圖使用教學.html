🧭 晶圓地圖(缺陷空間簽名)使用教學

把「瑕疵偵測②」逐 die 的判定攤回晶圓座標,一眼看出缺陷的空間模式, 當製程根因追查的線索。截圖為 2026-07-19 在示範資料(兩片晶圓、W1 植入邊緣模式)上實拍。

這個工具告訴你什麼

結論意義常見根因方向
聚一團(可信)缺陷集中在某一區局部污染、曝光局部問題
偏邊緣(可信)缺陷偏在晶圓外圈塗佈/蝕刻邊緣效應
線狀(可信)缺陷連成一條線機械刮傷(手臂/夾具)
看不出模式隨機散佈或樣本不足大概率非系統性問題
同 lot 多片同模式(並排自行比對)該批共用設備/程序
誠實原則:判定用 within-wafer permutation 校準 (只在這片實際存在的 die 位置間重排)。隨機資料就說隨機、樣本太少就說看不出來—— 所以它說「有模式」時,才值得叫工程師來看。

事前準備:兩樣東西

  1. 瑕疵偵測②的套用結果(本工具的判定來源)。
  2. 一張 metadata CSV,一列對一張影像:
filename,wafer,die_x,die_y,lot
n00.jpg,W1,-2,-2,L1
d00.jpg,W1,10,0,L1
...
  • filename(必要):影像檔名,用來和資料夾裡的影像對起來。
  • 座標兩欄(必要):die_x/die_y、x/y、col/row 等常見欄名會自動認出。
  • wafer 欄(建議):哪一片晶圓;wafer_id、片號 等也認得。
  • lot 欄(選填):批號,有給才有「同 lot 並排」。
  • 欄名不合以上也沒關係——畫面上四個下拉可手動指定任何欄。

步驟 1:先跑瑕疵偵測 ②(前置)

此示範:W1 的 8 顆可疑 die 圍成外圈 → 偏邊緣(可信); W2 沒有可疑 die → 看不出模式——缺陷太少(誠實說不知道,而不是硬給結論)。

步驟 5:看統計細節(選看)

每片地圖下的「詳細(統計)」可展開 method line 與三個簽名各自的 p 值—— 跟主管或工程師對「多有把握」時用;平常看粗體結論即可:

判定門檻(保守設計):die ≥20、可疑 ≥5、正常 ≥5 才進統計; 三簽名做 Bonferroni 校正;結論屬探索性(exploratory), 當根因線索用,不是嚴格推論。

  • wafer_signatures.csv — 每片一列:wafer_id、lot、n、k、verdict、三個 p 值、理由

常見問題

  • 「看不出模式」是壞事嗎? 不是——多數晶圓本來就該隨機。 這個「不亂報」正是結論可信的原因。
  • 抽檢(不是每顆 die 都有影像)可以用嗎? 可以,有幾顆畫幾顆; 統計 null 也只在「實際存在的檢測點」之間重排,不會因為抽檢位置偏(例如只檢外圈) 就誤報偏邊緣。
  • 一片要多少樣本? die ≥20、其中可疑與正常各 ≥5 才出統計; 不足時地圖照畫、結論誠實寫「看不出模式+原因」。
  • 同一批很多片怎麼看? 給 lot 欄 → 自動並排(每列 4 片、 每 lot 最多顯示 12 片,超過會明講)。
  • 會動到我的資料或設定嗎? 不會:只讀來源資料夾與②結果; 匯出只寫你另選的目錄。
